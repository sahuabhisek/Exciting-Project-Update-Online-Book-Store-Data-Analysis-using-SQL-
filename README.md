📚 Excited to share my latest SQL Analytics Project: Online Book Store Data Analysis! 🚀

As part of my continuous learning journey in Data Analytics and SQL (inspired by Sathish Dhawale Sir's 30-Day SQL Course), I built and analyzed a complete relational database for an Online Book Store!

🔍 Project Highlights & Key Key Insights:
🔹 Database Setup: Created structured schemas for Books, Customers, and Orders tables with Foreign Key relationships and imported real-world CSV datasets.
🔹 Data Cleaning & Queries: Solved 20 business problems ranging from basic filtering to advanced aggregation.
🔹 Advanced SQL Concepts Used:
  - Joins (INNER JOIN, LEFT JOIN) for multi-table analysis
  - Aggregations (SUM, AVG, COUNT, GROUP BY, HAVING)
  - Data Hygiene & Logic (COALESCE for handling NULL values, Stock reconciliation)
  - Sorting & Filtering (ORDER BY, LIMIT, WHERE, BETWEEN)

📊 Key Business Questions Answered:
1. Top revenue-generating customers and high-value orders.
2. Genre-wise sales distribution & stock management tracking.
3. Inventory forecasting by calculating remaining stock after order fulfillments.

🛠️ Tech Stack: PostgreSQL / SQL
